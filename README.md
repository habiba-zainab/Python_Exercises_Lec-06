## 📚 Overview
This repository contains my practice work for Lecture 06, focusing on defining and using functions, understanding different function types, working with parameters, and solving problems through recursion.

## 📖 Topics Covered

### ✅ Function Basics
* Defining and calling functions
* Function syntax and structure
* Return statements and return values
* Function scope (local vs global variables)
* Docstrings and function documentation

### ✅ Types of Functions
* Built-in functions (`print()`, `len()`, `type()`, `input()`)
* User-defined functions
* Lambda (anonymous) functions
* Higher-order functions
* Functions as first-class objects

### ✅ Default Parameters
* Positional arguments
* Keyword arguments
* Default parameter values
* Variable-length arguments (`*args`, `**kwargs`)
* Argument unpacking

### ✅ Recursion
* Base case and recursive case
* Call stack and execution flow
* Factorial and Fibonacci using recursion
* Recursive vs iterative approaches
